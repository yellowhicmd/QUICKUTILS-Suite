QUICKUTILS Terminal Launcher v1.0 
A lightweight, terminal-based Windows utility suite featuring a Cyberpunk Blue ANSI interface. Designed for fast, keyboard-driven system administration and routine maintenance using native Batch scripting and embedded PowerShell commands. Zero external dependencies required.
---
## 📥 Download

For the pre-compiled, ready-to-run executable, download `QUICKUTILS.exe` directly from the **[Releases](../../releases)** page.
--
🛠️ Key Features
- **System & Network Diagnostics:** Query OS specifications, monitor drive storage capacity, and run instant ping tests across Cloudflare and Google DNS.
- **Maintenance & Optimization:** Flush the DNS resolver cache, purge temporary files (`%TEMP%`), and manage heavy memory processes.
- **Network Utilities:** Extract saved Wi-Fi profiles/passwords using native `netsh` commands and quickly access common web shortcuts.
- **Automation & System Toggles:** Execute directory backups using Robocopy, update system software via `winget`, inspect live battery telemetry, restart Explorer.exe, and toggle Windows Dark/Light modes via registry tweaks.
